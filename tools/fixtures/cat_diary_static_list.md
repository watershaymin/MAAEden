# 无滚动条三条日记

来源：2026-10-16，MuMu `127.0.0.1:16384`，MaaFramework 5.12.3，1280×720 控制器截图。

日记实际显示猫神神社遗迹、劳拉巨蛋城、莎蒂拉体育场三条线索，印章 5/7。右侧没有滑块，旧 `diary_scrollbar` 颜色规则无法确认布局，初次任务保护停止，尚未追猫。

`cat_diary_static_list.npz` 的 `before`、`after_down`、`after_up` 是同一份日记在滑动前、向下浏览后和恢复后实机截图，三条内容、印章和布局均不变。滑动使用现有列表手势 `(780,430) → (780,175)` 及反向。原始截图和手势日志保留于本地 `debug/cat/2026-10-16/route-probe/`。

`StaticList.png` 来自固定右侧边缘 `[952,128,24,330]`，不包含可变猫文字。识别阈值 0.98，仅在旧滑块识别失败、标题、面板和关闭按钮均已通过时启用；随后还需双向滑动，各自重新稳定读取，确认三条内容、印章及无滚动条布局均不变。任意变化保护停止，不能因滚动条缺失直接把可见三行当成全部。

负样本 `four_top`、`four_bottom`、`four_three_visible_done` 来自既有四条列表样本。其中最后一张虽然可见三行都已完成，仍识别为四条，不能通过静态三条识别。回放还覆盖五种合成滑块高度及空白画面。

`test_cat_diary_static_list_replay.py` 验证原生模板、三条真实 OCR、印章、双向复核和负样本；`test_cat_diary_static_list.py` 覆盖内容、印章、条目数和布局变化，以及停止与过期保护。无滚动条三条布局的验证不表示其他未知列表长度已受支持。
