# 猫咪日记四条列表回放

样本来自 MuMu `127.0.0.1:16384`，MaaFramework 5.12.3，1280×720 控制器截图。

- `top` / `bottom`：2026-10-06 温泉交互后同一份日记的列表顶部和底部。
  顶部为已完成、扎博、帕德列；底部为扎博、帕德列、巴尔沃基。
  滚动条在 `[962,130,4,328]` 内采样，深棕色滑块高度约 240px，对应四条记录。
  原先仅读可见三行会把底部的扎博误认为已完成第一只猫重新待找。
- `three_visible_done`：2026-10-05 最终画面，可见三行均完成，但滚动条仍对应四条列表。
  这张图不能独立证明隐藏的第一行完成；旧版终点记录仅证明当时可见三行红爪印。

`tools/test_cat_diary_list_replay.py` 检查四组：顶部、底部、三个可见爪印的列表长度，
以及真实 OCR、上下两页重叠核对、四条排序和恢复顶部的整段读取。
控制器禁止设备输入；滚动在内存中切换两张真实页面，不把离线输入回放当成实机路线验证。

当前运行时接受滑块高度 305～325px（三条）和 230～247px（四条）；其他长度保护停止。
四条布局有实机样本，三条布局保留旧界面兼容并有合成边界检查，未新增三条布局实机验证。
