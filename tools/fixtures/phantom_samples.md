# 幻璃境识别样本

`phantom_samples.npz` 保存 PNG 编码的 uint8 数组，加载使用 `allow_pickle=False`。
每张画布为 1280×720，只保留相关识别区域，其他位置为黑色，原坐标不变。
采集日期：2026-09-21；实机为 MuMu，MaaFramework 5.12.3，控制器短边 720。

| 键 | 来源 / 用途 |
| --- | --- |
| white_warning | 白票尚未使用的继续扫荡提示 |
| white_available | 用户参考图中持有白票的选图页标志，缩放至 1280×720 |
| no_white | 无白票的选图页负例 |
| first | 壹之境三个事件；必须避开左侧两个 |
| second | 贰之境的小事件图标、宝箱和普通灰猫 |
| third | 叁之境的大事件图标、蓝箱和机械猫 |
| fourth | 肆之境的事件与另一只普通猫 |
| baruoki_all | 伍之境三个闭合宝箱，中间箱尺寸更小、事件高度更高 |
| baruoki_middle | 两侧已开，只剩中间箱；检查不会漏掉中间事件 |
| baruoki_balloon | 左侧气球出口与右侧箱子；检查气球不会被当成宝箱 |
| terminal_title | 实机终之境入场标题，验证 OCR 终境分支 |
| black_reference | 用户提供的巴尔沃基黑猫参考图，原尺寸放入 1280×720 画布 |

`tools/test_phantom_recognition.py` 使用 Maa 原生识别器检查白票正反例、各场景事件数、
普通猫与黑猫区分。黑猫目前的正例来自参考图；该测试不等同于实机触发黑猫或终境。
终之境已另行实机进入并验证立即停止。宝箱分类修复使用本轮留存截图回归，未再耗票重跑。
