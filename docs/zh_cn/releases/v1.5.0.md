本版继续完善猫咪日记，支持无滚动条的三项列表，补齐红叶街道、妖魔殿和龙神池的已验证路段，并修复传送确认文字重叠导致的误停。

下载 Windows x64 ZIP，解压后运行 `MFAAvalonia.exe`。包内包含 GUI、MaaFramework、Python 和 OCR 模型，无需另装 Python 或 .NET。建议解压到新目录，保留旧版及其配置。

## 猫咪日记

- 支持无滚动条的三项日记布局，通过上下双向核验读取完整列表；继续兼容已验证的滚动列表。每次交互后重新读取线索，直到全部条目完成。
- 修复传送确认行的重叠 OCR 字框误读。遇到重叠时对原始像素整行重读，保留完整目的地、确认句和按钮校验；不会根据预期地点删改数字，也不会忽略真实楼层编号。
- 改进小地图定位和换道过程，补充地图特征不足时的轮廓、混合定位及整图重新校准验证。

## 路线补充

- 红叶街道新增小尺寸羽毛识别和已标定道路；经那古萨无南门连接路进场。
- 妖魔殿补齐实际进殿路线与门口识别，核对到达地图后继续追踪。
- 更正龙神池“鸟一飞走路就被堵住了”的线索，补入首图东侧传送点至下层环道的已实走道路。未显示支路的首次空目标搜索仅有离线边界验证，不扩大为所有分区均已支持。
