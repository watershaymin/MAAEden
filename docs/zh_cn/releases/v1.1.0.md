本次更新支持红绿票独立扫荡和副本分支路线选择，并完善猫咪日记的寻猫流程。

下载 Windows x64 ZIP，解压后运行 `MFAAvalonia.exe`。包内包含 GUI、MaaFramework、Python 和 OCR 模型，无需另装 Python 或 .NET。先在安卓模拟器中手动完成游戏账号登录，再选择设备和任务。

## 副本扫荡

- 红票、绿票分别选择副本和每次运行的扫荡场数，先红票后绿票；各默认 4 场，设为 0 则不执行该票种。部分绿票副本每场需要 2 张票，次数按场数计算。
- 选择有分支的副本后显示“扫荡路线”下拉框，各副本独立保存选择。支持虚时层四本、冥峡界、未来嘉路雷亚，以及扭曲的大漩涡四个入口的七条已确认路线。
- 大漩涡可自动滚动查找所选路线。恩特纳默认路线仍为“皱囊虫遗迹”，可改选“死亡迷宫”或“晓之塔 图里亚尔瓦”。
- 修复多个设置互相覆盖导致副本、次数、路线或补票选择丢失的问题，并改进次元夹缝蓝门的进入与点击。
- 红票、绿票、猫掌券补充可分别开启，默认关闭；保留旧单副本参数兼容，不使用克洛诺斯之石。

当前账号实测古代、现代嘉路雷亚点击跳过后直接结算，未出现分支菜单，因此暂未增加路线选项。大漩涡菜单中仍显示“？？？”的未解锁路线也不列入选项。
