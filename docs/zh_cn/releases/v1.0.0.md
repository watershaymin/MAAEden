MAAEden 首个 Windows x64 正式运行包，内含 GUI、MaaFramework、Python 和 OCR 模型，解压后运行 `MFAAvalonia.exe`。无需另装 Python 或 .NET；先在安卓模拟器中手动完成游戏账号登录，再选择设备和任务。

## 梅纳斯谜晶鉴定

- 从梅纳斯试炼进入谜晶鉴定，每批消耗 25 个谜晶；可设置批数，`0` 表示鉴定本次持有的全部完整批次。
- 逐把读取武器类型、物理/魔法攻击与词条，按玩家设置自动锁定；已锁定的武器保持锁定。
- 支持自定义白值、词条组合和武器类型筛选。实机采样 3 批、75 把武器，记录 30 种已观察到的词条，尚不能视为完整词条池。

默认锁定条件：物理攻击 **大于 210**（杖改看魔法攻击），并满足以下任意一项：

1. 同时有中毒增伤和疼痛增伤。
2. 中毒增伤、疼痛增伤至少有一个，并且「HP 最大时伤害」「暴击威力」「全属性攻击力」至少有两个。

识别不确定或出现未知页面时停止并记录原因；谜晶余量不足 25 个时保留余量。

## 运行包与验证

- 固定 MFAAvalonia v2.16.1、MaaFramework 5.12.3 和 Python 3.12.10，采用 .NET 10 Release 自包含编译，并包含 Agent 临时目录兼容补丁。
- 发布流程执行资源检查、Schema 校验、单元测试与原生 Agent 握手及注册检查。ZIP 附带 SHA256 校验文件。
- 谜晶鉴定已做实机单批流程、锁定幂等性和 OCR 样本回放验证；默认规则覆盖所有 5 词条组合、8 类武器及 210/211 边界。连续多批、背包满、网络异常与余量不足场景尚未完整实机验证。

当前实机适配为 16:9 横屏安卓模拟器，截图按短边 720 缩放。详细设置见包内 `docs/zh_cn/develop/menas_appraisal.md`。
