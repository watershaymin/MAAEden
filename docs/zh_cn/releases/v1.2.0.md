本次更新完善猫咪日记的跨区域寻猫与场景识别，并修复梅纳斯试炼结算动画期间过早操作的问题。

下载 Windows x64 ZIP，解压后运行 `MFAAvalonia.exe`。包内包含 GUI、MaaFramework、Python 和 OCR 模型，无需另装 Python 或 .NET。先在安卓模拟器中手动完成游戏账号登录，再选择设备和任务。

## 猫咪日记

- 支持米格兰斯城一楼上二楼、纳兹里克前往冻时领域东侧、异元晶控制所内部房门与扶梯，以及妖魔殿冰坡前往昆仑山脉。
- 温泉改用直接传送点，依据已验证的场景标志完成无小地图寻猫；补充空中城郭伊斯亚等地点的道路标定。
- 修正斑鸠之乡地点信息，改进蛇骨岛分区、时代切换等待、传送确认及空白海域地图拖动。
- 改进不同尺寸羽毛图例与角色位置识别，排除任务标记干扰，处理路口遮挡、斜坡与地图纵向移动。
- 修复海之国佐见明亮海滩背景下普通对话无法继续的问题，保留文字与边框双重确认。
- 继续以日记线索变化和红爪印确认进度；支持满卡换新卡，异常位移、未知场景和超时仍停止并保留现场。

截至 2026-09-17，74 个不同地点中已有 27 个完成实机寻猫，47 个尚未验证。地点库收录不代表全部路线可用；未解锁传送点、未验证楼层或无法识别的地图仍可能需要手动处理。

- 2026-09-17 运行包独立 Agent 一次连续无干预完成尼尔瓦、尤尼冈、猫神神社，确认三个红爪印，印章由 2 增至 5。该验证通过原生客户端调用，尚未由 GUI 前端按钮启动完整一轮。
