红票、绿票扫荡和梅纳斯试炼现在可以分别选择队伍。本版同时收录 v1.2.0 之后已合入的白票幻璃境自动处理与小地图导航改进。

下载 Windows x64 ZIP，解压后运行 `MFAAvalonia.exe`。包内包含 GUI、MaaFramework、Python 和 OCR 模型，无需另装 Python 或 .NET。

## 队伍选择

- “副本跳过”新增独立的“红票队伍”和“绿票队伍”，“梅纳斯试炼”新增“挑战队伍”。
- 可选择保持当前队伍（默认）或队伍 1～10，编号按游戏队伍页底部圆点从左到右计算。
- 仅切换预先配置的队伍，不修改成员、装备或技能。请提前配好对应队伍；任务不会主动恢复运行前的队伍。
- 在入场确认页切换，逐次核对选中栏位，确认成功后才提交扫荡或挑战。识别失败或切换未生效时停止。
- 红绿票分别保存选择；0 次的票种和零票的梅纳斯不切队。幻璃境结束后恢复扫荡、补票返回入场页时重新核对。
- 修正多段参数覆盖可能互相覆盖的问题，队伍、次数、副本和路线可以同时生效。命令行新增 `--red-team`、`--green-team` 和 `--team`。

## 白票幻璃境

- 副本跳过新增“获得白票时自动刷幻璃境”开关，默认关闭。
- 开启后，持有或获得白票时处理幻璃境，再继续剩余扫荡；最后一场掉落白票也会处理。
- 进入终之境立即停止后续任务并提示“你撞大运了”，保留现场交给玩家。未确认的随机房间停止并保留现场。

## 小地图导航

- 寻猫和月度刷怪流程接入共享小地图定位，减少已支持路段重复展开整图。
- 传送、换层和战斗等状态变化后重置定位，关键目的地仍通过整图复核。
- 稀疏小地图仍可能回退整图；地点库收录不代表所有地点和楼层都已实机验证，具体范围见包内开发文档。
