# 副本入口与指定次数跳过

## 独立前置：次元夹缝蓝门

入口 `DungeonEntrance`，客户端显示“前往副本蓝门”，流程位于
`assets/resource/pipeline/dungeons.json`。

1. 从可操作主界面打开底部“地图”。
2. 在世界地图选择 `???` 分类，点击“次元夹缝”。
3. 核对“即将移动到次元夹缝”的确认框后点击“是”。
4. 落地后展开右上区域地图，核对左上“次元夹缝”，再关闭区域地图。
5. 沿落点的同一条横向道路向左走，寻找带蓝色花纹的独立门框。
6. 点击该门上方的交互标志，确认打开标题为“平行迷宫”的选图界面。

前置只负责到达副本选择页面；已经位于该页时直接完成。
已知的队伍选择页、详情页和二级地图会先逐层关闭，每类最多处理 5 次。
详情页外侧仍可点到其他地点，因此关闭详情时先读取地图标签，避开其按钮范围选择空白处；
不能固定点击同一坐标。选图页判定还会排除仍然打开的详情层，不能仅依赖顶部标题。
蓝门识别匹配门体，不能使用通用感叹号代替，否则可能点击宝箱或旁边的事件。
移动最多 5 步，每步 600ms；交互后以页面识别确认成功。

```powershell
python -X utf8 tools/run_startup.py --adb-path '<adb.exe 路径>' --address '<ADB 地址>' --task DungeonEntrance
```

## 消耗约束

用户允许为测试执行跳过，并允许使用星天引导之证补充红票或绿票。
禁止使用克洛诺斯之石补充。实际弹窗显示“要使用1次导证之力，回复红色解锁卡吗”，
同时显示导证之力剩余次数。必须核对导证之力、1 次消耗、对应票种与正数剩余量，才点击“使用”。
随后核对“获得了红色解锁卡7个”再确认；补票会回到原来的继续页，本身不执行跳过。
补票后重新提交下一次跳过，补票过程不增加完成次数。

红票已实测：以 7 张红票开始，要求 8 次，自动补票后完成第 8 次并返回蓝门。
绿票补充仅按相同界面字段适配，尚未实机触发。

每次跳过还消耗猫掌特急券，调查结束时剩余 4 张。其补充弹窗使用独立的导证之力额度，
本次未授权补充该券，检测到该提示后立即停止并报告已完成次数。红绿票与猫掌券均不使用克洛诺斯之石补充。

## 当前实现与验证边界

`agent/dungeons.py` 负责地图标签搜索、队伍确认页核对与结算计数，
以及选图页层级判定和空白处选择；普通点击、拖动、按钮识别仍定义在 `dungeons.json`。
每次跳过在“获得道具 / 要继续跳过吗？”页计数；达到要求后点击结束并确认恢复主界面。
连续跳过前必须观察上一轮结算页离开，防止重复计算同一张画面。

客户端选项与命令行均支持指定次数：

```powershell
python -X utf8 tools/run_startup.py --adb-path '<adb.exe 路径>' --address '<ADB 地址>' --task DungeonSkip --dungeon snake_damak_vh --count 2
```

月影森林困难已实测自动定位、打开队伍页，并自动连续跳过 2 次后返回蓝门。
非常困难已完成从蓝门外启动的 8 次红票跳过与自动补票测试。
红票奖励中的星天引导之证加成说明不视为补票提示；随机获得白色解锁卡时，确认奖励后继续结算。
参数、计数和石头否决回归检查已通过；离线截图已验证正常/遮暗选图页、启用/灰色跳过按钮及继续页。
最终验证：15 项副本测试、8 项移动测试、25 项截图识别检查，以及 Schema、maa-tools 校验通过。
正式选图代码已无消耗复测蛇肝达玛克二级入口、古代席尔贝利亚大陆晶入口和冥峡界跨地区路径。
