# 小地图定位与移动

`NavigationMiniMapRoute` 已实现按小地图观测推进的移动闭环。开始时展开区域图建立本次会话的模型，
之后每次滑动主要读取右上小地图；定位证据不足、距离上次校准超过 45 秒或抵达终点时才重新展开区域图。
猫咪日记、基础移动、巴尔沃基巡路和星天试炼巡路已默认共用此定位方式。
`NavigationMiniMapRoute` 继续提供独立指定路点的开发入口。

## 默认任务接入

- `Navigator.localize` 缓存当前地图会话；保留原任务的战斗、结算、对话和停止处理。
  首次核对已声明的地图名/别名，之后锁定完整名称；显式楼层列表始终精确匹配。
- 猫咪日记复用羽毛图例模板，在小地图两帧确认后投影到道路坐标。动态羽毛和粉色怪物图例
  不参与静态配准。视野外目标只作为最多 20 秒的搜索提示；接近 45px 或可见目标丢失时重新采集整图。
  只有场景交互与日记变化才能确认完成，坐标到达不代替猫交互。
- 传送、楼梯、门和无图连接路使旧会话失效；同名研究中心的上下层采用不同道路标识。
  纳兹里克先用已验证的固定图例恢复大地图原点，小图投影和终点核验统一到同一坐标系。
- 采集期间遇战会中止本次样本，调用原任务恢复并重新采集，最多 5 次。
  普通遇战保留已完成的同图静态模型；首次建模被打断才丢弃未完成会话。
  展开前后发生战斗的截图不能混合建模。月度试炼仍由真实结算计数；独立终点核验后直接收图。
- 默认任务在小图不够明确而整图可靠时，可使用本次整图坐标继续有界移动；连续三次小图校验失败后
  暂按整图模式推进，每次校准仍尝试恢复小图。原任务的步数、位移与时间上限保持有效。
  指定路点开发入口仍为严格小图模式、最多 3 次。45 秒的定期身份核对不占失配预算。
- 温泉和纳兹里克无小地图连接路继续使用已有场景标志，不能凭空建立地图。

接入验证及未验证范围见 [默认导航接入报告](minimap-integration.md)。

## 模型与定位

模型有两个部分，不需要逐个地图新增角色模板：

- **视觉地图**：从实机区域图建立静态特征集合，展开前后差分限定道路、固定图例所在范围。
  排除当前角色附近区域。小地图每次独立与整图匹配，求当前的缩放和平移；不累加上一帧位移，避免长期漂移。
- **通行地图**：复用 `RoadMap` 的道路网格和最短路径搜索。有已标定中心线的地图使用中心线；
  其余地图使用同机位展开前后的道路差分。图例覆盖区可补齐直路或有唯一轴向入口的转角，不能跨未知空白造路。
  开关地图两侧背景取较亮值，并等待收图后的亮度稳定，避免传送淡入和人物姿态变化被误作道路。

角色定位使用连续 8 帧的颜色和变化量，整图使用 10 帧。固定黄色任务图例大多在时序差分中消失；
呼吸环则保留明灭弧线。对这些弧线拟合圆周，并检查 16 个方向中至少 13 个有变化证据。
多数帧稳定的内孔圆心用于精调。任务图标的小孔必须与脉动圆周一致，才能成为角色候选。
仍存在多个候选时，用同帧静态图例的几何变换、上次观测位置和单步移动范围排除不合理候选；
无法消歧就停止或重新展开地图。

视觉配准使用 SIFT 描述子、比例筛选和 RANSAC。至少需要 8 个有效匹配，分布在多个区域，
同时限制尺度、旋转和相邻两帧的定位差异；重复图例集中在一处不能算有效定位。
纹理稀少时改用道路轮廓：比较共同可见前景，要求 Dice 分数至少 0.68，且优于其他局部峰至少 0.08。
重复路段没有唯一峰时仍拒绝定位。初始特征变换的比例可在 0.55～1.25 倍范围内校准，必须与独立整图
位置相差不超过 7px；后续比例变化不能超过 0.02。轮廓也在起点校准比例，之后固定本次比例。
特征与轮廓路径可以交替，但相邻两帧坐标必须一致，误差不超过 3px。
地图名称使用保留抗锯齿笔画的原始 OCR，不符时补充灰度识别并有界重采样；仍精确核对全名和楼层。
协议参考：[OpenCV 特征实现](https://github.com/opencv/opencv/blob/4.x/modules/features2d/src/sift.dispatch.cpp)、
[受限仿射估计](https://docs.opencv.org/4.10.0/d9/d0c/group__calib3d.html)。

```mermaid
flowchart LR
    A[起点展开区域图] --> B[静态视觉特征与道路网格]
    B --> C[小地图多帧呼吸环与静态特征]
    C --> D[统一到整图坐标]
    D --> E[沿已确认道路有限滑动]
    E --> C
    C -->|证据不足或定期核验| A
    D -->|接近终点| F[展开整图独立复核]
```

模型仅保存在当前导航对象内，每次任务重新采集，尚未实现跨次运行持久化地图库。
目前是每次有限滑动后的在线采样闭环；8 帧之间各间隔 75ms，另外有截图、识别及动作耗时，
不等于持续按住摇杆时的高帧率同步追踪。没有用滑动时长推算当前位置。

## 使用

适用于国服、MuMu ADB、控制器缩放后 1280×720 的主界面。开始前先传送到相应地图。
`--map-name` 必须使用区域图全名，去除空格后精确匹配，包含楼层。
路点采用展开图坐标，最多 16 个；图像中的道路可通行性仍须由运行时确认。

```powershell
# 仓库现有开发环境；其他环境先安装 agent/requirements.txt。
& .\deps\startup-venv\Scripts\python.exe -X utf8 tools/run_startup.py `
  --adb-path 'E:\Program Files\Netease\MuMu\nx_main\adb.exe' `
  --address 127.0.0.1:16384 --task NavigationMiniMapRoute `
  --map-name '绿之村巴尔沃基' --waypoints '[[600,339],[600,254]]' --max-steps 30

& .\deps\startup-venv\Scripts\python.exe -X utf8 tools/test_minimap_navigation.py
```

入口已加入 Python Agent 注册及命令行任务列表，未放入默认 GUI 任务列表。
OpenCV 依赖为 `opencv-python-headless==5.0.0.93`，已同步开发和 GUI 依赖清单。
OpenCV 在首次地图定位时按需加载；默认巡路运行需要此依赖。
日志在 `debug/minimap-run/`，包含坐标、内点数、配准残差、开图次数和终点复核差异。

| 文件 | 用途 |
| --- | --- |
| `agent/minimap_navigation.py` | 时序圆环、视觉地图、配准、移动闭环及参数校验 |
| `agent/minimap_geometry.py` | 稀疏地图的轮廓匹配、唯一性检查和比例校准 |
| `agent/minimap_roads.py` | 已识别图例遮挡下的有限转角补全 |
| `agent/minimap_transitions.py`、`agent/data/minimap_transitions.json` | 已实走确认的离散机关连接与端点 |
| `agent/navigation.py`、`agent/main.py` | Custom Action 及 Agent 注册 |
| `assets/resource/pipeline/navigation.json` | 任务入口与完成态 |
| `tools/run_startup.py` | `--map-name`、`--waypoints`、`--max-steps` |
| `tools/test_minimap_navigation.py` | 实机样本回放与异常边界测试 |
| `tools/fixtures/minimap_navigation.npz` | 巴尔沃基、柯尼姆原始局部样本，含角色与任务图例重叠 |

## 2026-09-19 实机验证

MaaFramework 5.12.3、OpenCV 5.0.0、MuMu `127.0.0.1:16384`，2560×1440 缩放为 1280×720。
表内开图次数只统计导航过程，包含起点和终点，传送选图不计入。
终点差异是“最后一次小地图观测”与“随后独立展开图观测”的欧氏距离，**不是全程最大误差**。

| 地图与路线 | 滑动次数 | 展开区域图 | 中途校准 | 终点定位差异 |
| --- | ---: | ---: | --- | ---: |
| 巴尔沃基，落点到北侧路口 | 3 | 2 | 无 | 0.57px |
| 巴尔沃基，北侧横路、向下换道、主路往返 | 23 | 3 | 1 次定期校准 | 1.25px |
| 帕西法尔宫殿 1 楼，两条横路及上下连接路往返 | 20 | 3 | 1 次定期校准 | 0.78px |
| 柯尼姆，主路多次穿过黄色任务图标重叠区 | 10 | 2 | 无 | 0.54px |

相对每次移动都展开区域图，以上长路线显著减少开图。柯尼姆没有添加新的道路中心线或地图图片模板，
使用运行时自动提取的道路。全部路线均由实际位移和终点独立观察确认，未以已发送滑动作为成功。

研发中两次柯尼姆路线曾失败：首次任务图例小孔与角色圆心混淆，被整图交叉核验拦截；
随后一次出现背景上的第二个脉动候选，定位停止。已分别增加脉动圆周校验与基于地图坐标的候选消歧，
再完成表内往返验证。自动道路提取在图例密集处还可能绕路，不能视为完整、最优的地图建模。
重叠路段曾出现约 10px 的横路纵向偏差，终点亚像素差异不代表所有中间帧同样准确。

原始序列保留在 `debug/minimap/2026-09-19/`，回归所需的局部素材另收录在 fixtures。
旧导航 8 项、猫咪日记 75 项及新增定位 18 项回归通过。Schema 和 maa-tools 资源检查通过。
检查期间曾发现 25 个已有、受 Git 跟踪的图片文件缺失，已按 HEAD 原样恢复；原因未确定。

正式命令行入口另完成柯尼姆 6 次滑动、2 次开图，终点差异 0.97px，达到
`NavigationMiniMapComplete`，退出码 0。更新运行包后，通过原生客户端连接独立 Python Agent，
再次完成同路线 6 次滑动、2 次开图，终点差异 0.40px，同样达到完成节点、退出码 0。
这验证了打包后的依赖、注册和实际控制链；未通过 GUI 前端按钮启动该实验任务。

## 边界

后续已完成 [15 张新区域扩图实测](minimap-survey.md)：7 张到达、8 张在初始校准阶段停止。
扩图暴露了稀疏特征、地图名 OCR 与道路连通性问题，并补充了星之塔出口重叠的圆环修正。
详细目标、失败历史和范围以该报告为准，不能把上面少数地图的成功率外推到所有地图。
针对这些问题的后续修复与复测见 [修复报告](minimap-repair.md)，上述 7/15 保留为修复前基线。

- 单任务最多 5 分钟、默认 60 次滑动，最多 3 次中途重新校准。连续三步没有预期位移即停止。
  截图和动作沿用现有用户停止检查，未知画面不继续盲走。
  若换道直接越过纵向目标且无法停在目标附近，停止并提示改选平台，避免在连接路两端反复往返。
- 机关连接需要独立实走标定，不能把图上断续台阶自动连成普通道路。当前只确认伊丝卡莉欧忒由下平台到上平台。
  执行前核对地图、起点和按钮，执行后重新核对地图名及落点；同一连接每次任务最多使用一次。
- 终点必须经展开图复核，误差超过 8px 或距最后目标超过 10px 则失败。
- 独立指定路点入口不自动跨未知地图或楼层；任务已有的传送和楼层交互仍由任务本身确认。
- 其他分辨率、长期反复运行、接入后新一轮完整猫咪日记以及全部地图尚未验证。
  严重遮挡、只剩重复直路或特征太少时仍可能需要开图，甚至安全停止。
