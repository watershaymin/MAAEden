# 梅纳斯试炼

任务标识和入口为 `MenasTrial`，显示名称为“梅纳斯试炼”。
流程位于 `assets/resource/pipeline/menas_trial.json`，模板位于 `assets/resource/image/MenasTrial/`。

## 使用方式

先运行“启动并登录”，或手动进入可操作的游戏主界面，再运行“梅纳斯试炼”。
也可以从活动列表、梅纳斯试炼选关页开始。

- 每次任务挑战一次 **STAGE SS**，消耗 **1 张梅纳斯入场券**。
- 玩家需提前配置能够通关的队伍、技能和游戏内相关预设。
- 任务不编辑、切换队伍，不选择技能，不切换 REPEAT、倍速、逃跑、搭档或 Another Force。
- 任务不购买入场券，不循环刷完全部入场券；再次运行会开始新的一场。
- 游戏、分辨率和账号条件与[启动并登录](./startup.md)相同。

命令行调试沿用已有脚本，增加任务参数：

```powershell
python -X utf8 tools/run_startup.py --adb-path 'E:\Program Files\Netease\MuMu\nx_main\adb.exe' --address 127.0.0.1:16384 --task MenasTrial
```

脚本默认仍执行 `StartUp`，试炼任务的整段运行上限为 15 分钟。
日志目录为 `debug/menas-trial-run/`。Ctrl+C 会停止自动操作，不会自动退出游戏里的战斗。

## 流程与完成条件

1. 点击底部活动按钮，再点击“梅纳斯试炼”横幅。
2. 同时识别试炼标题与右侧独立的 `SS` 字样，点击 STAGE SS。
3. 识别“进行挑战”并点击一次，等待进入战斗。
4. 同时识别右下角“攻击”和左上角“状态确认”，仅点击攻击。
5. 识别“获得道具”结算页，点击中部空白区域推进经验结算。
6. 识别 `Congratulations`，继续点击，推进 Cleared、战斗奖励和逐条通关条件展示。
7. 结算之后，底部菜单和地图按钮同时恢复为正常亮度，才到达 `MenasTrialComplete`。

主界面完成节点仅能从结算链到达；进入任务时看见主界面会开始导航，不会直接报告完成。
结算弹窗优先于主界面识别，避免透过弹窗遮罩提前结束。返回主界面后不再点击活动或开始下一场。

导航按钮最多命中 3 次；提交挑战最多 1 次；攻击最多 100 次；道具结算最多 8 次；
通关提示最多 16 次。导航每阶段等待 30～60 秒，入场和战斗每阶段等待 180 秒，
结算每阶段等待 60 秒。攻击次数是操作保护上限，不等于游戏回合数。
识别不到下一状态或超出命中上限后会超时失败，不会无条件继续点击。

## 本次观察到的战斗与结算界面

- 等待操作时，左上角显示状态确认、REPEAT、倍速和逃跑按钮；下方显示角色、技能名称和 HP/MP。
- 点击攻击后，角色执行玩家保存的技能。技能动画中攻击按钮与左上角控制按钮消失，
  因此等待其重新出现即可进入下一轮，无需识别伤害、敌方血量或技能过程。
- 顶部显示 Another Force 等战斗条，右侧有搭档相关按钮，当前流程不操作这些控件。
- 胜利后左上角显示“获得道具”“经验值”，下方显示角色等级与经验条。
- 离开经验结算后返回场景，出现 `Congratulations / Cleared` 和战斗奖励，
  然后逐条展示通关条件。每次点击可能只推进一条，需要继续识别提示标题。

模板只截取按钮和固定文字，不依赖队员头像、技能名称、奖励数量、活动日期或加成角色。
STAGE S 与 SS 的蓝色底板高度相似，因此 SS 模板仅包含两个 S，并使用相关性匹配；
不能用大面积蓝色底板的相似程度区分关卡。
