# 梅纳斯谜晶鉴定

任务标识与入口：`MenasAppraisal`，GUI 显示“梅纳斯谜晶鉴定”。
游戏内名称为“谜晶”；入口位于梅纳斯试炼右下角。

## 使用与设置

从可操作主界面、活动列表、梅纳斯试炼选关页或鉴定道具页运行。
默认开启自动锁定，使用“毒痛增伤组合”：**杖的魔力大于210，其余武器的攻击大于210**，
并且满足以下任一组合：

1. 同时具有“中毒时强化+30%”和“疼痛时强化+30%”。
2. 具有上述毒痛词条中的至少一个，并具有“HP最大时伤害+25%”“暴击威力+40%”
   “全属性攻击力+25%”中的至少两种。

白值210不合格，211开始合格；杖只看魔力，其他武器只看攻击。重复识别到同一个词条不会算作两种。
默认白值要求可调整，词条组合固定。GUI也可切换“自定义白值与词条”，沿用原有自由筛选；
自定义模式须至少设置一项白值下限或目标词条，否则会在消耗前报错。
关闭自动锁定时，只鉴定、读取并保存结果。

| 设置 | 行为 |
| --- | --- |
| 鉴定批数 | 默认1批，每批25个；0表示处理任务开始时持有量中的全部完整批次，最大999批。 |
| 锁定规则 | 默认毒痛增伤组合；可切换自定义白值与词条。 |
| 默认组合白值 | 杖魔力／其他武器攻击须严格大于设置值，默认210。 |
| 适用武器 | 杖、剑、刀、斧、枪、弓、拳、锤，可多选；空选表示全部类型。 |
| 攻击／魔力下限 | 比较实际白值，包含等于；0表示该项不参与判断。 |
| 攻击与魔力组合 | 两项均设置时，选择全部达标或任意一项达标。 |
| 目标词条 | 多选实测词条；可选择必须同时具有全部词条，或至少具有一个。 |
| 白值与词条组合 | 两组条件同时满足，或任一组满足；没有设置的一组不参与判断。 |
| 其他目标词条 | 填放大镜详情中的完整名称，用分号分隔；与勾选的词条共同判断。 |

在自定义模式中，例如选择攻击下限200、魔力下限200、白值任意达标，勾选“暴击威力+40%”与
“HP最大时伤害+25%”、词条任意满足、白值与词条同时满足，则规则为：

```text
(攻击 >= 200 或 魔力 >= 200)
且 (具有暴击威力+40% 或 具有HP最大时伤害+25%)
且 武器类型符合所选范围
```

自定义模式只设白值时仅按白值判断；只设词条时仅按词条判断。完全空的规则不会被视作“全部锁定”。
这是一组可组合的规则；不同类型需要不同规则时，可在 GUI 中分别配置任务。

## 流程与停止行为

1. 复用梅纳斯导航，点击右下“谜晶鉴定”。连续读取两次持有数，一致后规划完整批次。
2. 点击“自动鉴定”，确认弹窗中的道具确为谜晶、数量为25，再点击一次“鉴定”。
3. 等待结果页，按五行五列逐把选择。切换后等待详情区域稳定，连续读取白值。
4. 打开放大镜，连续读取两次完整词条，再关闭详情复核原武器白值。
   外层“力量·智力·速度·耐力·精神·幸运提升”对应详情的“全状态20UP”，不能只读外层简写。
5. 符合条件且原本未锁定时，点击锁按钮，确认“已锁定”及说明文字，关闭弹窗并核对闭锁图标。
   已有锁定不点击。锁状态不明确、OCR不可靠或页面不符时停止。
6. 25把全部处理后点击“继续鉴定”回到道具页，复核持有数恰好减少25；达到计划批数即结束。

任务保留所有生成的装备，不出售、不分解，也不解除已有锁定。
不足25个不提交残余鉴定：全部模式正常结束，指定批数未完成时报告实际进度并返回失败。
每批预算10分钟，单次等待结果最多45秒；所有循环和操作会检查用户停止。
未知网络／背包弹窗保留现场，提交后不自动重试消耗。

不从已有结果页或放大镜弹窗自动恢复：停止后请手动处理该批并点“继续鉴定”，再重新运行。
这避免把未确认数量的旧批次当成完整25把。

每次运行写入 `debug/menas-appraisal/日期时间.json`，包含规则、白值、完整词条、命中与锁定状态、
已确认消耗和完成批数。每读完一把即保存，失败时保留部分结果。
若 `unconfirmed_consumption` 为 `true`，表示已经尝试提交但尚未确认结果页，实际消耗需要人工核对；
不能把此时的 `consumed` 当作最终消耗量。

## 代码、验证与维护

- `assets/resource/pipeline/menas_appraisal.json`：识别、点击、页面稳定等待；复用现有梅纳斯导航。
- `assets/resource/image/MenasAppraisal/`：真实1280×720截图裁剪的模板，不依赖武器外观或随机数值。
- `agent/menas_appraisal.py`：参数、白值／词条解析、条件组合、计数、锁定闭环与报告。
- `agent/data/menas_affixes.json`：稳定词条标识、采样数量、出现次数及来源。
- `tools/update_menas_appraisal_options.py`：从目录生成 GUI 多选项，保留其他任务配置。
- `tools/fixtures/menas_appraisal_samples.json`：75把已解析样本；OCR回归样本另存同目录。

多选按 Project Interface V2 的 `checkbox` 定义，使用不同字典键合并选中的词条，
没有通过重复覆盖数组丢失前面的选择。本地Schema、MFAAvalonia v2.16.1的多选与合并实现均已核对；
协议参考：[Project Interface V2](https://maafw.com/docs/3.3-ProjectInterfaceV2/)。

命令行使用JSON规则文件。使用默认毒痛组合：

```json
{
    "batches": 1,
    "auto_lock": true,
    "rule_mode": "poison_pain",
    "primary_above": 210
}
```
