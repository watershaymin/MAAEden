## 根因与修正

1. **道路清楚但缺少纹理。** 原先仅依赖 SIFT，火山、时之塔等地图匹配点不足。
   新增颜色混合道路的轮廓配准，要求足够的共同前景、唯一局部峰和相邻帧坐标一致。
   比较独立峰而不是同一宽峰的边坡；重复结构仍拒绝定位。原有特征数量和几何阈值未放宽。
2. **展开图比例不固定。** 塔尔加纳山道的展开图比通常比例更小。起点以独立整图圆心校准比例，
   后续保持固定比例；已由特征路径确认常规比例时，切换轮廓定位无需重新要求位置等于起点。
3. **地图名文字被过滤损坏。** 酸性沼泽的硬白色过滤破坏抗锯齿笔画，曾误识别为“酸性洛泽”。
   复用原始 OCR 节点，并在不匹配时尝试保留强度的灰度图、有界重采样；地图全名及楼层仍精确匹配。
   旧 KMS 的彩色背景曾让“旧”字被识别成“I旧”，灰度补充识别修复了该失败样本，没有删字或模糊名称匹配。
4. **背景被误当成道路。** 传送淡入的偏暗帧，以及开关地图时人物姿态变化，都会污染差分。
   改用两侧场景较亮值作为基底，并等待收图后的亮度稳定，减少假道路和人物残影。
   稳定性分别检查整体亮度偏移与局部变化，避免酸性沼泽的持续雾气动画被误判为未完成淡入。
5. **图标切断转角。** 重新校准时角色环盖住拐角，导致工业废墟原本可走的路断开。
   现在从未腐蚀的道路宽度取入口，只在已识别遮挡框内、轴向入口唯一时补角，不跨未知空白补路。
6. **图上连接并不等于可停留路面。** 秘密基地原目标 `(705,390)` 位于自动换道中段。
   实走会在约 `y=461` 与 `y=359` 之间整段换道，因此改标上端平台 `(705,358)`，原失败记录保留。
   加入纵向越过目标后的停止提示，避免在两端反复往返。这一图不能计作原目标成功。
7. **断续台阶实际是机关。** 伊丝卡莉欧忒连续滑动无位移，点击场景感叹号才会跳到上平台。
   已独立确认下端约 `(640,439)`、上端约 `(640,282)`；新增已验证机关连接，不把台阶填为普通道路。
   只在地图名、起点和按钮一致时点击，观察过渡过程，再重新核对地图名与落点。

## 模型与边界

主定位使用运行时地图，没有新增逐地图的角色模板。机关按钮增加了一个真实截图模板；
机关端点属于人工实走标定数据。轮廓匹配不能自动推导机关操作。

龙神池和秘密基地复测使用自动道路，取消了原测试参数中的人工中心线；
山道仍沿用原标定中心线。旧样本中保留中心线的路线会在结果表中注明。
因此“到达成功”不等于“通用自动建模已经覆盖所有地图”。

判定仍要求终点独立展开图复核：距目标不超过 10px，大小地图差异不超过 8px。
开图统计包含起点和终点，不含事先标定、传送选图和进入房间。
机关交互单列，不能把 0 次滑动、1 次机关交互误读为没有移动。

实走通过的是有限路线，不是长时间可靠性统计；没有全程位置真值。
未验证跨图/跨楼层连续规划、野外战斗恢复、其他分辨率、完整猫咪日记和全部地图。
实验入口仍未替换默认猫咪日记，也未加入默认 GUI 任务列表。
