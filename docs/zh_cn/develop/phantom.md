# 白票与幻璃境

幻璃境作为“副本跳过”（`DungeonSkip`）中的“获得白票时自动刷幻璃境”开关，默认关闭，不单独列为任务。
未勾选时，获得白票只确认奖励并继续跳过，不使用白票。

勾选后，在开始扫荡前检查选图页白票标志；扫荡期间得到白票时，确认本场结算后结束连续跳过，
进入幻璃境。幻璃境结束并回到蓝门后，重新选择原副本，继续尚未完成的场数。
幻璃境和补票过程都不增加扫荡计数。即使白票出现在最后一场，也先处理白票再结束任务。

Custom 参数为 `auto_phantom` 布尔值；界面选项使用独立配置节点合并，不影响副本、次数和补票设置。
已有白票也通过副本跳过任务处理；红绿票场数都为 0 时不运行。内部 `PhantomRealm` 动作保留供流程复用。
幻璃境入口条件是可操作主界面或蓝门选图页；不支持从任意中途画面恢复。
选图后必须核对“消耗 1 个白色解锁卡”“幻璃境”“困难”，才点击移动。

```powershell
python -X utf8 tools/run_startup.py --adb-path '<adb.exe 路径>' --address '<ADB 地址>' --task DungeonSkip --auto-phantom
```

## 行为

- 壹之境只点击右侧柜子上方的事件点，避开左侧猫爪统计。
- 普通房间先找猫和三个宝箱；图标需与箱体或猫的识别结果对应，再点击出口。
  队伍遮挡箱体时移动重新观察，收到奖励后才记为开箱；不能只凭事件高度推断宝箱。
- 巴尔沃基场景（画面标题“伍之境”，用户参考图中的第六层）先检查左侧黑猫。
  黑猫在三个箱子开启后优先点击；不会按已经访问的房间数量推算终点。
- 此岸之境从左到右处理全部事件，再从右侧离开，确认迷宫奖励页和蓝门外主界面。
- 识别到“终之境”立即停止整个任务并弹出“你撞大运了”，保留游戏画面交给玩家。
  GUI 使用节点 focus 对话框；命令行调试入口在 Windows 使用独立原生消息框。
  GUI 的 `focus.aborted` 同步取消队列，需配套 [客户端焦点补丁](gui.md)；仅更新资源不足以更新旧客户端。

标题只在换层时出现，所以当前房间状态保留到下一次识别到新标题。
事件标志采用不同尺寸模板；镜头移动后重新截图，等待图标稳定。
以相邻画面的背景位移判断搜索边界，不累计滑动时间估算位置。
每次幻璃境最多 600 秒，每层最多 18 次搜索，整体最多 120 次事件或移动。
遇到尚未确认的房间、奖励或出口会保存现场并停止，不自动重复耗票。

## 实机记录（2026-09-21）

运行环境为 MaaFramework 5.12.3、MuMu ADB、短边 720 的 1280×720 截图。
红票使用蛇肝达玛克非常困难，绿票使用蚀时尤尼冈困难的“变异战舰”路线。
本次调查按累计重置次数交替红绿票，优先使用重置次数少的一种；导证之力补充后核对到账。
按用户随后指定的本轮上限，红票最多重置 10 次、绿票最多 30 次，含指定上限前已经消耗的次数。
任一票种到上限后不再进入该票种的下一批；两者都到上限仍未到目标房间则结束调查。
此轮长时间调查的调度保存在本地调试脚本中，普通客户端任务仍按用户配置场数执行。

首次幻璃境分段验证了壹、贰、叁、肆、此岸，以及地牢奖励、猫和右侧出口。
随后已经自动完成“壹 → 贰 → 此岸”和“壹 → 此岸”，回到蓝门后自动接回原副本扫荡。
这不代表所有随机房间或从任意中途状态恢复均已验证。
第 8 张白票连续自动通过壹、贰、叁、肆，到达用户参考图对应的伍之境，随后进入终之境。
终境标题首次被识别时立即停止，没有发送终境内的点击，Windows 已显示“你撞大运了”原生提示。
本轮实际重置红票 8 次、绿票 8 次、猫掌特急券 2 次；未达到用户后续指定的 10 / 30 次上限。

本次伍之境只确认开启了两侧两个箱子，中间箱漏开；旧版把相近高度的气球出口误当成第三个箱子。
修复删除了按高度推断宝箱的兜底，新增中间箱盖模板。原生截图回归确认：三个箱子均能识别，
仅余中间箱时仍能识别，气球不再作为宝箱。该修复未再次耗票实机重跑。
黑猫本轮未出现，优先级和参考图识别已离线检查；猫之境、稻草人之境未遇到，当前保留现场停止。

运行包已补充客户端焦点中止回调。旧 GUI 的离线对照会在队列取消检查中失败，新 GUI 能同步清空队列、
取消令牌并阻止重复执行；原生 Maa 测试也验证 Custom 内停机可返回，且终境 focus 携带提示及中止标记。
完整 GUI 游戏流程没有另行耗票重跑，实际刷票使用同进程注册 Custom 动作的 MuMu 调试入口。

收尾检查：55 项副本测试、9 项幻璃境规则测试、20 项月度副本测试、3 项原生选项检查、
6 项原生幻璃境截图/停机检查及 5 项打包检查，共 98 项通过；Schema、maa-tools 和差异检查通过。
已同步 `install/`，运行包 Agent 握手、`PhantomRealm` 注册、正常退出，以及编译客户端队列中止检查通过。
框架仍输出既有的 `native/plugins` 目录加载告警，本轮 Agent 通信检查未受影响。
