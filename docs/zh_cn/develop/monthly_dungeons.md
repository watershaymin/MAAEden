# 星天试炼·指定副本

任务入口 `MonthlyTrialDungeons`，从主界面或记录 → 勋章 → 试炼页开始，
读取本期三个通关副本目标，与 `agent/data/dungeons.json` 的副本跳过目录匹配。
包含普通“开拓的考验”、星天“开拓的考验”和星天“踏破的考验”。
每个未达成且可跳过的目标只跳过一次，不自动领取奖励，结束时停留试炼页。

## 使用与消耗

- 国服、ADB、16:9 横屏，MaaFramework 控制器缩放后 1280×720。
- GUI 勾选“星天试炼·指定副本”；无需手填每月副本名，默认最多运行 30 分钟。
- 沿用当前队伍与已有副本跳过能力。目录中不可进入、不可跳过、无法匹配或同名多路径的项目记录原因后略过。
- 目标没有指定难度时，优先票数较少的入口，同票数优先困难；同一路径不同难度只选择一个。
- 每次消耗对应红绿解锁卡及猫掌特急券。复用现有红绿票导证之力补充规则；禁止使用克洛诺斯之石。
  猫掌券不足或补票核对失败时停止，不把资源不足伪装成任务完成。
- 队伍页已核对副本、难度和票数，但跳过按钮没有启用时，返回主界面并略过该项，不改为正常进入。

## OCR 与执行流程

1. 复用每月 200 胜任务的 `MonthlyNavigator.open_trials()` 进入试炼页。
   读取报酬截止日期，向上滚动到顶部，连续两次文字及位置不变才确认边界。
2. 短距离向下滚动，保留完整卡片的重叠区域。标题、通关说明和右侧状态必须属于同一卡片，
   连续两次识别一致才接受。支持 OCR 横向拆字、空白、常见引号与标题间隔符。
   “领取奖励”和“已领取奖励”都视为已完成；不把其他卡片的按钮套用到目标上。
3. 必须读全三个副本目标才开始消耗票券。每个方向最多 64 次滚动；OCR 为空、读数不一致、
   到底仍未读全时失败停止。副本名称不按月份缓存，也不写死当前样例。
4. 完整名称与目录的名称、确认名、末级入口名匹配，并区分平行迷宫和异境。
   异境的地区目标可匹配该地区下已确认支持跳过的楼层。禁止名称子串或模糊匹配，
   例如“次元战舰”不能匹配“次元战舰方舟”。普通副本存在多条同名路径时略过，不猜入口。
5. 复用 `DungeonEntrance` 和 `DungeonNavigator.skip(target, 1)`；结算次数核对仍由原副本模块负责。
6. 每次跳过后重新从试炼列表顶部扫描。游戏会把完成的卡片排到后面，使用标题、类型、名称、
   难度组成的键重新定位，不依赖原位置。必须确认对应卡片已完成，否则停止，不追加一次跳过。
7. 后续月份或目标集合变化、已完成状态倒退都停止。同一个副本若对应多条任务，复核后已完成的其他卡片也会略过。

普通页面操作节点位于 `assets/resource/pipeline/monthly_dungeons.json`；
卡片解析、目录匹配、扫描和完成复核位于 `agent/monthly_dungeons.py`。
新动作已纳入 Agent、命令行注册及 GUI Agent 冒烟检查。
