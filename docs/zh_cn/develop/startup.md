# 启动并登录

移动、传送与区域地图定位的开发说明见 [基础移动与传送](navigation.md)。

任务入口为 `StartUp`，在客户端显示为“启动并登录”。流程位于
`assets/resource/pipeline/startup.json`，识别图片位于 `assets/resource/image/Startup/`。

## 使用条件

- 游戏：另一个伊甸国服，包名 `com.xd.anothereden`。
- 模拟器已运行，ADB 可连接，账号已在游戏内登录并有可读取的存档。
- 16:9 横屏，控制器短边缩放至 720，即识别基准为 1280×720。
- 使用支持 `And` 和模板匹配 `method: 10001` 的 MaaFramework 5.3 或更新版本；本次实测为 5.12.3。

首次账号登录、验证码、实名认证及新账号开场流程需要手动完成。
本任务复用游戏保存的账号状态，不保存或输入账号密码。

在通用客户端中选择“安卓端”“官服”，连接模拟器后运行“启动并登录”。
当前只接入实际验证的安卓国服，已移除模板中的桌面控制器、B 服和示例任务入口。

## 流程与结束条件

1. 通过 `StartApp` 启动 `com.xd.anothereden/net.wrightflyer.toybox.AppActivity`，不会主动结束已运行的游戏。
2. 识别标题页“读取游戏”按钮并点击；已处于游戏主界面时直接结束。
3. 识别登录公告右上角的关闭按钮并点击，优先处理公告。
4. 若进入梅纳斯试炼选关页，同时确认页面标题、SS 标志和右上关闭键后，点击关闭键返回。
5. 同时识别底部“菜单”和“地图”按钮才判定完成，不依赖场景或角色外观。

菜单和地图采用亮度敏感的模板匹配，避免将弹窗遮罩后的按钮识别为可操作状态。
标题和公告操作各最多命中 3 次；启动和读取后的单阶段等待上限为 180 秒，
关闭公告后的单阶段等待上限为 120 秒。梅纳斯选关页最多关闭 2 次，关闭后的等待上限为 15 秒。
无法识别的画面会超时失败，不会无条件点击确认。
用户可以随时停止任务。每日奖励、版本下载和网络异常弹窗尚未获得样本，暂不自动处理。

## 命令行调试

安装 Python 依赖 `maafw==5.12.3` 后，在仓库根目录运行：

```powershell
python -X utf8 tools/run_startup.py --adb-path 'E:\Program Files\Netease\MuMu\nx_main\adb.exe' --address 127.0.0.1:16384
```

路径和端口只是本次设备示例，请以实际配置为准，不会写入公共任务资源。
脚本使用 `Encode` 截图和 `AdbShell` 输入，额外检查屏幕比例，并设置整个任务 5 分钟上限。
按 Ctrl+C 停止，成功退出码为 0，失败为 1，手动中止为 130。
日志输出至被 Git 忽略的 `debug/startup-run/`；成功必须同时满足框架成功和最终节点为 `StartUpWorldReady`。

### 2026-09-19 明亮场景主界面识别

帕西法尔宫殿一楼的明亮地面改变半透明地图按钮外观，旧 `WorldMap.png` 得分为 0.899，导致寻猫移动后等待主界面超时。
为 `StartUpWorldReady` 补充 `WorldMapBright.png`，裁剪自实机 `[250,653,56,39]`，采用更严格的 0.97 阈值；旧模板仍为 0.9，菜单与地图双重识别不变。
原生框架回放确认宫殿落点和明亮区域可识别，区域地图、世界地图、猫咪日记、普通对话与合成半亮度主界面均不命中。
合成 75% 亮度样本仍命中旧模板（0.951），属于原有识别边界，不能据此宣称任意遮罩均可排除。
本轮只扩展 `StartUpWorldReady`，其他任务独立定义的主界面节点未同步扩展，也未验证它们从宫殿明亮区域启动。
运行包实测修复后重新传送宫殿一楼并完成寻猫；75 项猫咪日记测试、8 项导航回归、Schema 与 maa-tools 校验通过。

### 2026-09-24 梅纳斯选关页恢复

当天从模拟器桌面启动，读取存档并自动关闭公告后，画面停留在梅纳斯试炼选关页。

新增 `StartUpCloseMenasStages`，从启动、读取游戏和关闭公告三个节点均可进入。
复用 `MenasTrialStagesReady`（标题与 SS 标志）和 `CatDiaryCloseButton`，同时命中才点击关闭键；
仍以 `StartUpWorldReady` 独立确认完成，不点击关卡或挑战按钮。

`StartUp → StartUpCloseMenasStages → StartUpWorldReady`，只关闭一次，随后成功读取当日三个猫槽。
