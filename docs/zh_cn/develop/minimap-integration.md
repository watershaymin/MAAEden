# 小地图导航默认接入

2026-09-19，MuMu `127.0.0.1:16384`，MaaFramework 5.12.3，控制器 1280×720。

## 接入范围

猫咪日记的追猫、控制所跨层、城堡楼梯、昆仑冰坡前后定位，以及基础单步、巴尔沃基巡路、
星天 200 胜巡路，默认使用同一套导航会话。今后使用 `Navigator.position/move` 的巡路也默认接入。
传送和楼层变化调用 `reset_navigation`，不能仅凭同名标题复用楼层模型。
菜单切换、传送确认、猫交互和战斗结算仍由各任务原有页面状态判断。
温泉与已确认的无小地图连接路保留场景标志检查。

使用方式和 GUI 选项不变，用户无需另选实验入口。旧 `locate_legacy/position_legacy` 只供历史截图诊断，
正式任务不会调用；小图不足时回退的是本次整图多帧观测。

## 修复的兼容问题

- 羽毛目标两帧更新并投影；视野外目标有时效，接近或丢失时重新观测，不能用旧坐标宣布完成。
- 地图模型剔除移动羽毛和粉色怪物图例。纳兹里克支持固定图例校正整体平移，
  初始整图校验后可学习非标准地图比例，后续每帧独立配准。
- 长地图标题使用已实测的 780px 装饰识别范围，解决巢穴标题尾端超出原 650px 范围的问题。
- 地图采集中消失、进入战斗、开关图之间发生战斗时，丢弃不完整样本，由原任务恢复。
  已完成同图模型可以复用；首次建模不混合战斗前后的不同场景。
- 到达复核只采集独立整图坐标，不在驻怪点重新提取道路。巢穴巡路复用已验证的底部道路中心线。
- 月度移动被战斗截断时接受同方向的部分位移；仍拒绝明显反向位移和侧向偏离。
  门和传送标签点击识别框中心，避免随机落在识别框边缘。
- 控制所不能仅凭 10px 路点容差等待出口；须看到门按钮，必要时只在已验证的同一横路末端微调。
  小图连续校验失败的稀疏地图暂按整图观测推进，每次尝试恢复小图，原任务的步数和位移保护继续生效。
  控制所补充现场金色出口按钮样式，保留原白色样式；点击后仍必须核验新楼层与实际落点。
