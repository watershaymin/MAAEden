# 星天试炼·每月200胜

任务入口为 `MonthlyStarTrial`，仅处理记录 → 勋章 → 试炼中的
**星天·战士的考验：获得200场战斗的胜利**。不会执行其他月度试炼或领取全部奖励。

## 使用

- 先运行“启动并登录”，从可操作的主界面开始；也支持从已打开的试炼页开始。
- 另一个伊甸国服，MaaFramework 5.12.3，ADB，16:9 横屏，控制器缩放后 1280×720。
- 需已解锁虚时层 → 猫人世界 → 晓之塔图里亚尔瓦及一层魔物巢穴。
- 玩家提前配置可持续通关的队伍、技能与预设。流程仅点击攻击及奖励页空白处，
  沿用开场自动伤害，不更换队伍、技能、REPEAT、倍速或 Another Force。
- 从试炼页读取已有进度，补足到 200，不无条件再刷 200 场。已达成且显示“领取奖励”时直接完成。
- 完成后保留试炼页面，避免停在刷怪点继续遇敌；奖励由玩家按需领取。

```powershell
python -X utf8 tools/run_startup.py --adb-path 'E:\Program Files\Netease\MuMu\nx_main\adb.exe' --address 127.0.0.1:16384 --task MonthlyStarTrial
python -X utf8 tools/test_monthly_trial.py
```

整段任务默认最多 180 分钟；运行日志在 `debug/monthly-star-trial-run/`。
停止时不继续发送移动、攻击或关闭界面的操作；不会自动逃跑或退出游戏。

## 流程与计数

1. 按页面状态进入记录、勋章、试炼，有限滚动寻找目标卡片。必须在同一张卡片上
   同时识别星天标题和 `获得200场战斗的胜利 (n/200)`，连续两次读数一致才接受。
   达成后游戏隐藏分数，改为核对同一卡片的完整目标文字和“领取奖励”按钮，将进度视为 200。
2. 读取本期报酬截止日期，作为本次运行的月份标识。后续日期变化或计数倒退时失败停止。
3. 世界地图切换虚时层。若停在此前记住的子地图，先点广域，再选择猫人世界。
   寻找晓之塔文字，核对传送确认框后进入塔外传送点，再交互进入第一层。
   进门后先确认塔内小地图；进入巢穴后确认巢穴场景，避免打开地图中断自动走入。
4. 打开区域地图核对晓之塔标题、楼层及角色标记。第一层路线为
   `(653,530)` → `(653,445)` → `(474,445)` → `(474,531)`，再向左靠近巢穴门。
   最后一段角色标记会与巢穴图例重叠，改用真实门按钮识别交互，并核对到达魔物巢穴。
5. 巢穴落点约 `(711,402)`，向左移动至 `(670,402)` 附近，等待明雷刷新后主动接触角色。
   路点基于本机框架截图，不直接照搬用户提供的另一尺寸参考图。
6. 每场仅在识别奖励结算并回到主界面后计一胜。多次攻击、重复奖励画面、动画帧都不重复计数。
   若队伍开场自动击败敌人，未出现攻击按钮但有真实奖励结算，仍计一胜。
7. 寻路途中胜利也计入。每批最多 25 胜，退回巢穴入口一侧后打开试炼页核对游戏计数；
   尚未达到 200 时返回驻点继续。最终成功必须由游戏内分数或上述达成状态确认。
   返回点为 `(707,403)` 附近，使用 5px 容差，避免在出口箭头重叠区域追逐标记动画作过细微调。

页面识别、点击、滑动和模板在 `assets/resource/pipeline/monthly_trial.json`；
卡片数字解析、战斗结算去重、进度复核与路点循环在 `agent/monthly_trial.py`。
模块同时通过 Agent 和命令行注册；GUI 注册冒烟检查包含新动作。

## 保护与边界

- 单个路点最多 20 步；移动未发生且确有途中战斗时，在同一路点继续；无战斗的无位移或反向位移报错。
- 打开区域地图或记录时可能被明雷战斗打断；只处理已识别的战斗和结算，再有限重试。
- 菜单点击后等待目标页面，防止展开动画中重复切换。勋章页仍可确认但试炼标签未切换时，最多重试两次。
- 单场最多 180 秒、30 次攻击、12 次结算推进；驻点 120 秒没有新的胜利时停止。
- 列表最多滚动 18 次。读不到指定星天卡片、两次读数不一致、日期变化、进度不增长均失败。
- 金色角色标记使用多尺寸模板，限制在已确认地图的范围内，排除队员装备等地图外相似图案。
- 巢穴出口处标记可能与白色箭头重叠。模板失败时，限定在巢穴直路内提取金色环的连通区域，
  核对尺寸、比例、稀疏度及唯一性；连续两帧位置一致才接受补充定位。
- 移动从画面左侧 `(200,450)` 起手，采用最多 600ms 的小步并核对坐标。
  纵向连接路在松手后仍会自动走入，等待 1500ms 再打开地图，避免中断换道；已重复进塔验证三次。
  区域地图不暂停遇敌，打开后立即读取；关闭时等待底部菜单稳定，再识别主界面。
- 不自动购买、复活、回蓝、逃跑或处理未知弹窗。其他地图布局、分辨率、游戏改版需重新采样。
